# 농작물 이미지 분류 모델 구현 실습 과제

Paddy Doctor(벼 잎 이미지) 데이터로 **멀티태스크 분류 모델**을 구현한다.  
구현 환경은 **Google Colab + GPU**이며, 완성 코드는 `paddy_doctor_colab.ipynb`와 동일한 설정·출력 형식을 따라야 한다.

---

## 1. 실습 목표

- 압축된 농작물 이미지 데이터를 Colab에서 풀어 학습에 사용한다.
- 질병(`label`), 품종(`variety`), 생육 일수(`age`)를 함께 학습하는 멀티태스크 모델을 구현한다.
- 사전학습 CNN(ResNet18)을 백본으로 사용하고, GPU에서 학습한다.
- 학습이 끝난 뒤 **파일 업로드**로 이미지를 넣으면 예측 결과가 나오도록 한다.

---

## 3. 데이터

Kaggle **Paddy Disease Classification** zip을 사용한다.

zip 내부 구조(폴더가 한 겹 더 있어도 됨):

```text
paddy-disease-classification.zip
 ├─ train.csv
 ├─ sample_submission.csv          (없어도 됨)
 ├─ train_images/{질병라벨}/xxx.jpg
 └─ test_images/                   (없어도 됨)
```

`train.csv` 컬럼:

| 컬럼 | 설명 |
|---|---|
| `image_id` | 이미지 파일명 |
| `label` | 질병 클래스 |
| `variety` | 벼 품종 |
| `age` | 생육 일수 |

학습 이미지 경로는 반드시 아래 규칙을 따른다.

```text
{데이터루트}/train_images/{label}/{image_id}
```

## 4. 필수 하이퍼파라미터 (답안과 동일해야 함)

아래 값을 바꾸면 안 된다.

| 항목 | 값 |
|---|---|
| 백본 | `resnet18` (`timm`, ImageNet pretrained) |
| 입력 크기 `IMAGE_SIZE` | `224` |
| 정규화 mean | `[0.485, 0.456, 0.406]` |
| 정규화 std | `[0.229, 0.224, 0.225]` |
| 학습/검증 분할 | `test_size=0.2`, `stratify=label`, `random_state=42` |
| Optimizer | `Adam`, `lr=1e-3` |
| 에폭 `epochs` | `5` |
| 품종 손실 가중치 `WEIGHT_V` | `0.05` |
| 생육 일수 손실 가중치 `WEIGHT_A` | `0.0` |
| 질병 손실 | `CrossEntropyLoss` |
| 품종 손실 | `CrossEntropyLoss` |
| 생육 일수 손실 | `MSELoss` |
| 저장 파일 | `best_model.pth` |

통합 손실:

```text
loss = loss_d + (WEIGHT_V * loss_v) + (WEIGHT_A * loss_a)
```

검증 지표는 **질병 분류 정확도**만 사용한다.

### 문제 5. Dataset / DataLoader

클래스·함수 이름을 그대로 사용한다.

**5-1. `FastImageTransform`**

- 입력: uint8 CHW 텐서
- `/255.0` 후 `224×224` 리사이즈(`antialias=True`)
- ImageNet mean/std로 정규화

**5-2. `PaddyDataset`**

- `df["path"]`를 리스트로 보관한다. (`iloc`로 매 샘플을 읽지 않는다)
- 학습 시 `__getitem__` 반환값: `(image, label_id, variety_id, age)`
- 테스트 시(`is_test=True`) 이미지만 반환한다.
- 이미지는 가능하면 `torchvision.io.read_image(..., mode=ImageReadMode.RGB)`로 읽고, 실패하면 PIL로 읽어 CHW 텐서로 바꾼다.

**5-3. 배치 크기 `auto_batch_size()`**

VRAM 기준:

| VRAM | batch size |
|---|---|
| 20GB 이상 | 256 |
| 12GB 이상 | 192 |
| 8GB 이상 | 128 |
| 6GB 이상 | 96 |
| 4GB 이상 | 64 |
| 그 외 / CPU | 32 |

Colab T4(약 16GB)에서는 **192**가 나와야 한다.

**5-4. DataLoader**

```python
NUM_WORKERS = 2 if IN_COLAB else 0
```

- 학습 로더: `shuffle=True`, `drop_last=True`
- 검증 로더: `shuffle=False`, `drop_last=False`
- CUDA이면 `pin_memory=True`
- `NUM_WORKERS > 0`이면 `persistent_workers=True`, `prefetch_factor=2`

출력:

```text
DataLoaders are ready. batch_size=..., num_workers=...
```

### 문제 6. 모델 정의

클래스 이름: `PaddyMultiTaskModel`

요구사항:

- `timm.create_model(model_name, pretrained=pretrained, num_classes=0)`로 백본을 만든다.
- 특징 차원은 `self.backbone.num_features`를 사용한다.
- 헤드 3개를 만든다.
  - `fc_disease`: 질병 클래스 수
  - `fc_variety`: 품종 클래스 수
  - `fc_age`: 1 (회귀)
- `forward`는 `(out_d, out_v, out_a)`를 반환한다.
- 기본 인자: `model_name="resnet18"`, `num_diseases=10`, `num_varieties=10`

출력:

```text
Model class is ready
```

### 문제 7. 학습

모델을 다음처럼 생성한다.

```python
model = PaddyMultiTaskModel(
    model_name="resnet18",
    pretrained=True,
    num_diseases=num_diseases,
    num_varieties=num_varieties,
)
```

추가 요구사항:

1. CUDA이면 `memory_format=torch.channels_last`로 GPU에 올린다.
2. AMP를 사용한다.

```python
from torch.amp import GradScaler, autocast
scaler = GradScaler("cuda", enabled=use_cuda)
```

3. 학습 시작 시 아래를 출력한다.

```text
Start Training for 5 epochs... (AMP=True, batch_size=192)
```

(`AMP`, `batch_size`는 실제 환경 값)

4. 학습 루프
   - `optimizer.zero_grad(set_to_none=True)`
   - `autocast("cuda", enabled=use_cuda)` 안에서 손실 계산
   - `out_age`는 `view(-1)`로 MSE에 넣는다.
   - 20 스텝마다 tqdm에 `loss`를 표시한다.

5. 검증 루프
   - `torch.inference_mode()`
   - 질병 로짓만 사용해 `argmax`로 정확도를 계산한다.

6. 에폭마다 아래 형식으로 출력한다.

```text
Epoch {n} Result:
  Train Loss: 0.0000
  Valid Acc : 0.0000 (00.00%)
```

7. 검증 정확도가 최고이면 모델을 저장하고 아래를 출력한다.

```text
  [Create Best Model] Accuracy improved from ... to .... Saving model...
```

저장 내용은 딕셔너리여야 한다.

```python
{
    "model": model.state_dict(),
    "id2label": id2label,
    "id2variety": id2variety,
    "num_diseases": num_diseases,
    "num_varieties": num_varieties,
    "image_size": IMAGE_SIZE,
}
```

개선되지 않으면:

```text
  Accuracy did not improve from ...
```

8. 학습이 끝나면 아래를 출력한다.

```text
Training Finished.
Best Validation Accuracy: ...
```

## 7. 구현 시 주의사항

- 학습 전에 반드시 GPU 런타임을 선택한다.
- zip이 크면 Colab 직접 업로드보다 Google Drive가 빠르다. 그 경우 `MOUNT_DRIVE = True`로 바꾸고 `ZIP_PATH`에 Drive 경로를 넣는다.
- 클래스 이름, 출력 문구, 하이퍼파라미터는 이 문서에 적힌 그대로 사용한다.
- 검증 정확도 숫자 자체는 GPU/라이브러리 버전에 따라 조금 달라질 수 있다. 채점은 **설정과 출력 형식, 동작**을 본다.
