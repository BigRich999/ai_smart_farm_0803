병해충 이미지 분석 모델 구현 실습 과제
================================================================================

AI Hub 「국내 재배 아열대·열대 병해충 데이터」 Sample zip을 사용하여
작물·부위·병해충을 함께 예측하고, 병반/충해 영역을 박스로 표시하는
이미지 분석 모델을 구현한다.

구현 환경은 Google Colab + GPU 이다.
완성 코드는 이 문서의 설정·출력 형식을 따라야 한다.


1. 실습 목표
--------------------------------------------------------------------------------
- Sample zip을 풀어 JPG 원천데이터와 JSON 라벨을 1:1로 맞춘다.
- JSON에서 작물(대분류), 부위(중분류), 병해충(소분류), bbox, 환경센서 값을 추출한다.
- Hugging Face Transformers의 사전학습 Vision Transformer(ViT) 백본에
  헤드 4개를 붙여 멀티태스크 분석 모델을 학습한다.
    (1) 작물 분류
    (2) 부위 분류
    (3) 병해충 분류
    (4) bbox 회귀 (정규화 좌표)
- AutoImageProcessor 로 전처리하고, ViTModel 의 pooler_output 을 특징 벡터로 쓴다.
- 학습이 끝난 뒤 파일 업로드로 이미지를 넣으면
  작물/부위/병해충 Top-3와 bbox가 그려진 결과를 보여 준다.

4. 필수 하이퍼파라미터 (바꾸면 안 됨)
--------------------------------------------------------------------------------
항목                         값
---------------------------  ------------------------------------------
라이브러리                   transformers (Hugging Face)
백본 모델 MODEL_NAME         google/vit-base-patch16-224
백본 클래스                  transformers.ViTModel
전처리                       AutoImageProcessor.from_pretrained(MODEL_NAME)
입력 크기 IMAGE_SIZE         processor.size 기준 (기본 224)
정규화                       processor 의 image_mean / image_std 사용
                             (ViT: [0.5, 0.5, 0.5] / [0.5, 0.5, 0.5])
학습/검증 분할               test_size=0.2, stratify=disease, random_state=42
Optimizer                    AdamW, lr=2e-5, weight_decay=0.01
에폭 epochs                  8
작물 손실 가중치 WEIGHT_C    0.30
부위 손실 가중치 WEIGHT_P    0.20
bbox 손실 가중치 WEIGHT_B    0.10
작물/부위/병해충 손실        CrossEntropyLoss
bbox 손실                    SmoothL1Loss
저장 파일                    best_model.pth

통합 손실:

    loss = loss_d + (WEIGHT_C * loss_c) + (WEIGHT_P * loss_p) + (WEIGHT_B * loss_b)

검증 지표는 병해충 분류 정확도만 사용한다.
bbox 좌표는 이미지 너비/높이로 나눠 [0, 1] 범위의 (x, y, w, h) 로 넣는다.
timm / torchvision ResNet 등 CNN 백본은 사용하지 않는다.

문제 6. Dataset / DataLoader
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
클래스·함수 이름을 그대로 사용한다.

먼저 AutoImageProcessor 를 로드한다.

    from transformers import AutoImageProcessor

    MODEL_NAME = "google/vit-base-patch16-224"
    processor = AutoImageProcessor.from_pretrained(MODEL_NAME)

    def resolve_image_size(proc, default=224):
        # transformers 버전에 따라 size 가 dict, SizeDict, int 등으로 올 수 있음
        size = getattr(proc, "size", None)
        if size is None:
            return default
        if isinstance(size, (int, float)):
            return int(size)
        if hasattr(size, "get"):
            for key in ("height", "shortest_edge", "width"):
                val = size.get(key)
                if val is not None:
                    return int(val)
        for key in ("height", "shortest_edge", "width"):
            if hasattr(size, key):
                val = getattr(size, key)
                if val is not None:
                    return int(val)
        return default

    IMAGE_SIZE = resolve_image_size(processor)

출력:

    Processor ready: google/vit-base-patch16-224 (image_size=224)

6-1. PestDataset

- df["path"] 를 리스트로 보관한다. (iloc로 매 샘플을 읽지 않는다)
- crop_id, part_id, disease_id, bbox_norm(4,) 도 리스트로 보관한다.
- 이미지는 PIL.Image.open(...).convert("RGB") 로 읽는다.
- processor(images=..., return_tensors="pt") 로 전처리한다.
  반환되는 pixel_values[0] 을 모델 입력으로 쓴다.
  (직접 ImageNet mean/std 를 하드코딩하지 않는다)
- 학습/검증 __getitem__ 반환값:
      (pixel_values, crop_id, part_id, disease_id, bbox_norm)
- 테스트 시(is_test=True) pixel_values 만 반환한다.
- bbox_norm 은 float32 텐서 shape (4,) 이다.

6-2. 배치 크기 auto_batch_size()

ViT-base 는 CNN보다 VRAM을 많이 쓰므로 아래 표를 따른다.

    VRAM         batch size
    -----------  ----------
    20GB 이상    32
    12GB 이상    24
    8GB 이상     16
    6GB 이상     12
    4GB 이상     8
    그 외 / CPU  4

Colab T4(약 16GB)에서는 24 가 나와야 한다.

6-3. DataLoader

    NUM_WORKERS = 2 if IN_COLAB else 0

- 학습 로더: shuffle=True, drop_last=True
- 검증 로더: shuffle=False, drop_last=False
- CUDA이면 pin_memory=True
- NUM_WORKERS > 0 이면 persistent_workers=True, prefetch_factor=2

출력:

    DataLoaders are ready. batch_size=..., num_workers=...


문제 7. 모델 정의
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
클래스 이름: PestAnalysisModel

요구사항:

- from transformers import ViTModel, ViTConfig 를 사용한다.
- pretrained=True 이면
      ViTModel.from_pretrained(model_name)
  로 사전학습 가중치를 로드한다.
- pretrained=False 이면
      ViTModel(ViTConfig.from_pretrained(model_name))
  로 구조만 만든다. (추론 시 체크포인트 복원용)
- 특징 벡터는 backbone 출력의 pooler_output 을 사용한다.
  (없으면 last_hidden_state[:, 0] 사용)
- 특징 차원은 self.backbone.config.hidden_size 이다. (ViT-base: 768)
- 헤드 4개를 만든다.
    fc_crop     : 작물 클래스 수
    fc_part     : 부위 클래스 수
    fc_disease  : 병해충 클래스 수
    fc_bbox     : 4  (sigmoid로 0~1 범위)
- forward(pixel_values) 는 (out_c, out_p, out_d, out_b) 를 반환한다.
- 기본 인자:
      model_name="google/vit-base-patch16-224"
      num_crops=8, num_parts=3, num_diseases=18

출력:

    Model class is ready
    Backbone: google/vit-base-patch16-224 (hidden_size=768)


문제 8. 학습
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
모델을 다음처럼 생성한다.

    model = PestAnalysisModel(
        model_name=MODEL_NAME,
        pretrained=True,
        num_crops=num_crops,
        num_parts=num_parts,
        num_diseases=num_diseases,
    )

추가 요구사항:

1) 모델을 device 로 옮긴다. (ViT이므로 channels_last 는 쓰지 않는다)

2) Optimizer 는 AdamW 를 쓴다.

    optimizer = torch.optim.AdamW(
        model.parameters(),
        lr=2e-5,
        weight_decay=0.01,
    )

3) AMP를 사용한다.

    from torch.amp import GradScaler, autocast
    scaler = GradScaler("cuda", enabled=use_cuda)

4) 학습 시작 시 아래를 출력한다.

    Start Training for 8 epochs... (AMP=True, batch_size=24, backbone=google/vit-base-patch16-224)

   (AMP, batch_size 는 실제 환경 값)

5) 학습 루프
   - optimizer.zero_grad(set_to_none=True)
   - autocast("cuda", enabled=use_cuda) 안에서 손실 계산
   - forward 입력은 pixel_values
   - out_b 와 bbox_norm 은 float 로 SmoothL1Loss 에 넣는다.
   - 20 스텝마다 tqdm에 loss 를 표시한다.

6) 검증 루프
   - torch.inference_mode()
   - 병해충 로짓만 사용해 argmax 로 정확도를 계산한다.
   - 추가로 작물 정확도, 부위 정확도도 계산해 로그에 넣는다.

7) 에폭마다 아래 형식으로 출력한다.

    Epoch {n} Result:
      Train Loss : 0.0000
      Valid Acc  : 0.0000 (00.00%)   # 병해충
      Crop Acc   : 0.0000 (00.00%)
      Part Acc   : 0.0000 (00.00%)

8) 병해충 검증 정확도가 최고이면 모델을 저장하고 아래를 출력한다.

      [Create Best Model] Accuracy improved from ... to .... Saving model...

   저장 내용은 딕셔너리여야 한다.

    {
        "model": model.state_dict(),
        "model_name": MODEL_NAME,
        "id2crop": id2crop,
        "id2part": id2part,
        "id2disease": id2disease,
        "num_crops": num_crops,
        "num_parts": num_parts,
        "num_diseases": num_diseases,
        "image_size": IMAGE_SIZE,
    }

   개선되지 않으면:

      Accuracy did not improve from ...

9) 학습이 끝나면 아래를 출력한다.

    Training Finished.
    Best Validation Accuracy: ...

- 첫 실행 시 Hugging Face Hub에서 google/vit-base-patch16-224 가중치를
  다운로드한다. 네트워크가 필요하며, 캐시되면 이후에는 재사용된다.

  그 경우 MOUNT_DRIVE = True 로 바꾸고 ZIP_PATH 에 Drive 경로를 넣는다.
- JSON의 bbox 값과 센서 값은 문자열이므로 int/float 로 변환한다.
  빈 문자열은 NaN 으로 둔다.
- 이미지 크기가 512~3843 으로 제각각이다.
  AutoImageProcessor 가 모델 입력 크기(224)로 맞춘다.
  bbox 정규화는 리사이즈 전 원본 크기를 기준으로 계산한다.
- AdamW lr=2e-5 는 ViT fine-tuning 기본값이다. 1e-3 같은 큰 lr 은 쓰지 않는다.
- 클래스 이름, 출력 문구, 하이퍼파라미터는 이 문서에 적힌 그대로 사용한다.

  Sample 520장·18클래스라 병해충 정확도는 높지 않을 수 있다.
