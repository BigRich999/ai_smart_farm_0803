VLM 기반 농업 질의응답 시스템 구현
실습과제

AI Hub의 「노지 작물 질병 진단 이미지」 샘플데이터를 활용하여 고추·무·배추의 질병 이미지를 VLM으로 분석하고, 농업기술 관련 PDF 문서를 RAG 지식베이스로 구축하여 질병의 증상, 원인 및 관리 방법을 답변하는 멀티모달 농업 질의응답 시스템을 구현한다. Cursor AI를 활용하여 프로젝트 설계부터 코드 작성, 테스트 및 실행까지 전체 개발 과정을 수행한다.

활용 데이터

노지 작물 질병 진단 이미지 샘플데이터에서 다음 3개 작물의 정상 및 질병 이미지를 사용한다.

무
배추

농업기술 지식 데이터는 다음 5개의 PDF 문서를 활용한다.

농업기술길잡이47_채소병해충.PDF
농업기술길잡이-(2권) 채소병해충.pdf
5 고추 최종파일_단면.pdf
20 무_고화질_단면.pdf
농업기술길잡이128_배추.PDF
구현 내용

먼저 Cursor AI를 활용하여 Python 기반 프로젝트 환경과 Streamlit 웹 애플리케이션을 구성한다. 사용자가 고추·무·배추의 이미지를 업로드하고 농업 관련 질문을 입력할 수 있는 화면을 구현한다.

업로드된 이미지는 VLM에 전달하여 작물의 종류, 정상 또는 질병 여부, 관찰되는 증상 및 의심되는 질병을 분석한다. VLM의 분석 결과를 사용하여 농업기술 지식베이스에서 관련 정보를 검색할 수 있도록 검색 질의를 구성한다.

5개의 PDF 문서는 문서 로더를 이용하여 읽어오고, 적절한 크기로 문서를 분할한 후 임베딩하여 Chroma 또는 Qdrant 등의 벡터 데이터베이스에 저장한다. 사용자의 질문과 VLM의 이미지 분석 결과를 결합하여 관련 농업기술 정보를 검색하는 RAG 기능을 구현한다.

검색된 농업기술 정보와 VLM의 이미지 분석 결과를 LLM에 전달하여 최종 답변을 생성한다. 최종 답변에는 이미지 분석 결과와 함께 질병의 주요 증상, 발생 원인, 발생 환경 및 관리 방법을 포함하고, 답변에 활용한 농업기술 문서명을 함께 표시한다.

최종 동작 시나리오

사용자가 배추 질병 이미지를 업로드하고 다음과 같이 질문한다.

"이 배추에 어떤 문제가 있는 것 같나요? 증상과 관리 방법을 알려주세요."

시스템은 다음 순서로 처리한다.

농작물 이미지 + 사용자 질문 → VLM 이미지 분석 → 작물·질병·증상 추출 → 농업기술 RAG 검색 → 검색 결과와 이미지 분석 결과 결합 → LLM 답변 생성

예를 들어 VLM이 이미지에서 배추 + 질병 의심 + 잎의 이상 증상을 분석하면, 해당 분석 결과와 사용자의 질문을 검색어로 활용하여 5개의 농업기술 PDF에서 관련 정보를 검색한다. 이후 검색된 농업기술 자료를 근거로 질병의 특징과 발생 원인, 관리 방법을 종합하여 사용자에게 답변한다.

주요 구현 기능
고추·무·배추 농작물 이미지 업로드
VLM 기반 농작물 이미지 분석(OpenAI gpt-4o-mini 모델 사용)
작물 종류 및 정상·질병 상태 분석
질병 증상 및 특징 분석
농업기술 PDF 문서 로딩 및 전처리
Embedding 및 Vector DB 기반 농업 RAG 구축
VLM 분석 결과를 활용한 검색 질의 생성
사용자 질문과 이미지 분석 결과를 결합한 멀티모달 검색
RAG 기반 농업기술 정보 검색
VLM + RAG 기반 최종 답변 생성
참고 농업기술 문서 출처 표시
Streamlit 기반 농업 질의응답 서비스 구현
Cursor AI를 활용한 프로젝트 전체 개발 및 테스트
최종 결과

사용자가 농작물 이미지를 업로드하고 질문하면 시스템이 이미지의 질병 상태를 분석하고 관련 농업기술 자료를 검색하여, **「이미지 분석 결과 + 질병 정보 + 발생 원인 + 관리 방법 + 참고 문서」**를 포함하는 농업 질의응답을 제공하는 것을 최종 목표로 한다.
