Qwen3-VL 사용 VLM 기반 농업 질의응답 시스템 구현
실습과제

01_OpenAI 사용 실습과 동일한 농업 질의응답 파이프라인을, OpenAI gpt-4o-mini 대신 Qwen3-VL로 구현한다.
AI Hub의 「노지 작물 질병 진단 이미지」 샘플데이터(zip)를 활용하여 고추·무·배추의 질병 이미지를 Qwen3-VL로 분석하고, 농업기술 관련 PDF 문서(zip)를 RAG 지식베이스로 구축하여 질병의 증상, 원인 및 관리 방법을 답변하는 멀티모달 농업 질의응답 시스템을 구현한다.
Cursor AI를 활용하여 프로젝트 설계부터 코드 작성, 테스트 및 실행까지 전체 개발 과정을 수행한다.

활용 데이터

본 실습 폴더에 있는 다음 2개의 zip 파일을 사용한다.

    노지 작물 질병 진단 이미지_sample.zip
    pdf_data.zip

1) 노지 작물 질병 진단 이미지 샘플데이터
zip을 해제하면 원천데이터(이미지)와 라벨링데이터(JSON)가 함께 제공된다.

    원천데이터/01.고추/0.정상    60장
    원천데이터/01.고추/1.질병    60장
    원천데이터/02.무/0.정상      60장
    원천데이터/02.무/1.질병      60장
    원천데이터/03.배추/0.정상    60장
    원천데이터/03.배추/1.질병    60장

    라벨링데이터/01.고추/0.정상
    라벨링데이터/01.고추/1.질병
    라벨링데이터/02.무/0.정상
    라벨링데이터/02.무/1.질병
    라벨링데이터/03.배추/0.정상
    라벨링데이터/03.배추/1.질병

VLM 분석에 사용하는 입력은 원천데이터의 jpg/jpeg 이미지이다.
라벨링데이터의 JSON은 작물·정상/질병 정답 참고용이며, Qwen3-VL 입력으로 그대로 넣지 않는다.
JSON의 annotations.crop, annotations.disease, annotations.risk 필드를 활용할 수 있다.

    crop     1=고추, 2=무, 3=배추
    disease  0=정상, 그 외=질병 코드
    risk     0=정상, 1 이상=위험도

실습에서는 고추·무·배추 각 작물의 정상 이미지와 질병 이미지를 샘플로 사용할 수 있도록 정리한다.

2) 농업기술 지식 데이터
pdf_data.zip을 해제하면 다음 5개의 PDF 문서가 있다.

    농업기술길잡이47_채소병해충.PDF
    농업기술길잡이-(2권) 채소병해충.pdf
    5 고추 최종파일_단면.pdf
    20 무_고화질_단면.pdf
    농업기술길잡이128_배추.PDF

이 문서들을 RAG 지식베이스의 근거 자료로 사용한다.

구현 환경

OpenAI API는 사용하지 않는다. 이미지 분석(VLM)과 최종 답변 생성(LLM)은 Qwen3-VL로 수행한다.

    VLM/LLM 모델    Qwen3-VL (기본: Qwen/Qwen3-VL-4B-Instruct)
    실행 방식        Hugging Face Transformers 로컬 추론
                     (GPU 메모리에 따라 2B/8B Instruct로 변경 가능)
    양자화           GPU VRAM이 부족하면 4bit(BitsAndBytes) 사용 가능
    Embedding        로컬 임베딩 모델 사용 (예: BAAI/bge-m3)
    Vector DB        Chroma 또는 Qdrant
    UI               Streamlit
    개발 도구        Cursor AI

로컬 GPU가 없거나 모델 로드가 어려운 경우에 한하여 Qwen3-VL OpenAI 호환 API(예: DashScope, vLLM, Ollama)를 사용할 수 있다.
이 경우에도 모델 계열은 Qwen3-VL이어야 하며, gpt-4o-mini 등 OpenAI 비전 모델로 대체하지 않는다.

구현 내용

먼저 Cursor AI를 활용하여 Python 기반 프로젝트 환경과 Streamlit 웹 애플리케이션을 구성한다.
사용자가 고추·무·배추의 이미지를 업로드하고 농업 관련 질문을 입력할 수 있는 화면을 구현한다.
원천데이터에서 가져온 샘플 이미지를 사이드바에서 바로 선택할 수 있게 한다.

업로드된 이미지는 Qwen3-VL에 전달하여 작물의 종류, 정상 또는 질병 여부, 관찰되는 증상 및 의심되는 질병을 분석한다.
Qwen3-VL의 분석 결과는 JSON으로 구조화한다.

    crop                고추 | 무 | 배추 | 기타 | 불명
    health_status       정상 | 질병의심 | 판단불가
    observed_symptoms   관찰된 증상 목록
    suspected_diseases  의심 질병 목록
    severity            low | medium | high
    summary             한글 2~4문장 요약

Qwen3-VL의 분석 결과를 사용하여 농업기술 지식베이스에서 관련 정보를 검색할 수 있도록 검색 질의를 구성한다.

5개의 PDF 문서는 문서 로더를 이용하여 읽어오고, 적절한 크기로 문서를 분할한 후 로컬 임베딩 모델로 임베딩하여 Chroma 또는 Qdrant 등의 벡터 데이터베이스에 저장한다.
사용자의 질문과 Qwen3-VL의 이미지 분석 결과를 결합하여 관련 농업기술 정보를 검색하는 RAG 기능을 구현한다.

검색된 농업기술 정보와 Qwen3-VL의 이미지 분석 결과를 다시 Qwen3-VL(또는 동일 계열 텍스트 생성)에 전달하여 최종 답변을 생성한다.
최종 답변에는 이미지 분석 결과와 함께 질병의 주요 증상, 발생 원인, 발생 환경 및 관리 방법을 포함하고, 답변에 활용한 농업기술 문서명을 함께 표시한다.

스캔 이미지 중심 PDF처럼 텍스트 추출이 되지 않는 문서가 있으면, 해당 작물의 병해충 요지를 보완 텍스트로 인덱싱해도 된다.
단, 보완 자료만 사용하고 PDF 5종을 생략하는 것은 허용하지 않는다.

최종 동작 시나리오

사용자가 배추 질병 이미지를 업로드하고 다음과 같이 질문한다.

"이 배추에 어떤 문제가 있는 것 같나요? 증상과 관리 방법을 알려주세요."

시스템은 다음 순서로 처리한다.

농작물 이미지 + 사용자 질문 → Qwen3-VL 이미지 분석 → 작물·질병·증상 추출 → 농업기술 RAG 검색 → 검색 결과와 이미지 분석 결과 결합 → Qwen3-VL 답변 생성

예를 들어 Qwen3-VL이 이미지에서 배추 + 질병 의심 + 잎의 이상 증상을 분석하면, 해당 분석 결과와 사용자의 질문을 검색어로 활용하여 5개의 농업기술 PDF에서 관련 정보를 검색한다.
이후 검색된 농업기술 자료를 근거로 질병의 특징과 발생 원인, 관리 방법을 종합하여 사용자에게 답변한다.

고추 정상 이미지, 고추 질병 이미지, 무 질병 이미지에 대해서도 동일 파이프라인이 동작해야 한다.

주요 구현 기능
노지 작물 질병 진단 이미지_sample.zip 압축 해제 및 샘플 이미지 정리
고추·무·배추 정상/질병 이미지 업로드 또는 샘플 선택
Qwen3-VL 기반 농작물 이미지 분석 (OpenAI 비전 모델 사용 금지)
작물 종류 및 정상·질병 상태 분석
질병 증상 및 특징 분석
pdf_data.zip의 농업기술 PDF 문서 로딩 및 전처리
로컬 Embedding 및 Vector DB 기반 농업 RAG 구축
Qwen3-VL 분석 결과를 활용한 검색 질의 생성
사용자 질문과 이미지 분석 결과를 결합한 멀티모달 검색
RAG 기반 농업기술 정보 검색
Qwen3-VL + RAG 기반 최종 답변 생성
참고 농업기술 문서 출처 표시
Streamlit 기반 농업 질의응답 서비스 구현
Cursor AI를 활용한 프로젝트 전체 개발 및 테스트
최종 결과

사용자가 농작물 이미지를 업로드하고 질문하면 시스템이 Qwen3-VL로 이미지의 질병 상태를 분석하고 관련 농업기술 자료를 검색하여, 「이미지 분석 결과 + 질병 정보 + 발생 원인 + 관리 방법 + 참고 문서」를 포함하는 농업 질의응답을 제공하는 것을 최종 목표로 한다.

01_OpenAI 사용 실습과의 차이
01 실습은 OpenAI gpt-4o-mini와 OpenAI Embedding을 사용한다.
02 실습은 이미지 분석과 답변 생성을 Qwen3-VL로 수행하고, 임베딩도 로컬 모델을 사용한다.
질의응답 시나리오, 대상 작물(고추·무·배추), 활용 PDF 5종, Streamlit UI, RAG 결합 방식은 01 실습과 동일하다.
